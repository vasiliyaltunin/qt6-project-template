# Шаблон проекта для разработки в Qt6 с использованием GCC

Данный шаблон представляет собой проект Qt6 использующий шаблоны CMake для настройки проекта. Сразу после клонирования из репозитория можно преступать непосредственно к разработке вашего проекта не заботясь о дополнительной настройке.

## Шаблоны Cmake
Все настройки CMake распределены по шаблонам - файлам .cmake.in расположенным в папке cmake:

* settings.cmake.in - основные настройки
* conf.cmake.in - настройка подключаемых модулей
* qt6.cmake.in - настройки модулей и исходного кода проекта
* src.cmake.in - список файлов с исходным кодом включаемых в проект
* targets.cmake.in - настройка targets проекта

## Конфигурирование проекта

Запустите:

`cmake -S . -B build`

## Сборка проекта

Запустите:

`cmake --build build`

## Частые вопросы и ответы (ЧАВО)

1. Как поменять имя исполняемого файла?

   В файле `cmake\settings.cmake.in` в строке
`set (MY_EXE_NAME "qt6tpl")` замените `qt6tpl` на ваше имя файла.

2. Как добавить новый файл с исходным кодом в проект?

   В файле `cmake\src.cmake.in` добавьте новые строки с именами файлов в переменную `MY_QT_SRC` или `MY_QT_QML_SRC`
